# La Mesa de los Dos

Una pagina de una sola noche: tres cartas, cada una con tres recetas,
para cocinar lo mismo a la vez desde Medellin y Montreal.

## Como verla

Abre `index.html` en cualquier navegador. No necesita servidor ni instalar nada.

## Como publicarla en GitHub Pages

1. Sube este repo a GitHub.
2. Settings > Pages > Source: Deploy from a branch, rama `main`, carpeta `/ (root)`.
3. Queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`

## Estructura

- `index.html` - la pagina completa (HTML, CSS y contenido en un solo archivo)
- `img/` - las fotos de cada receta

El contenido de las cartas esta en la constante `CARTAS`, al principio del
`<script>` de `index.html`. Ahi se editan titulos, mensajes, recetas, videos y colores.
